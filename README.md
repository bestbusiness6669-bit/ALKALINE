# WEALTH VEDA - Product-Based Direct Selling (MLM) Platform

**Tagline**: Healthy Water • Healthy Wealth • Healthy Life  
**Product**: Premium 5-Liter Stainless Steel Bio-Alkaline Water Jar  
**Package Price**: ₹6,300  
**Direct Referral Income**: ₹300  
**Binary Pair Income**: ₹600 (1:1 Pair)  
**Daily ROI**: 0.5% (Monday to Friday only)  
**Daily Pair Ceiling**: 10 Pairs (₹6,000 / day max)  
**Income Capping**: 3X Package Earnings (₹18,900 max limit before requiring re-activation)  
**Minimum Withdrawal**: ₹300 (10% Deduction: 5% Admin + 5% TDS)  

---

## 🌟 Key Features

### 1. Corporate Website & Product Showcase
* Ultra-luxury Royal Blue, White, and Gold aesthetic with Glassmorphism cards and smooth Framer Motion animations.
* Interactive Income Calculator for ROI and Binary pair projections.
* Product benefits breakdown (Hydration, Antioxidants, pH 8.5–9.5 balance, Micro-clustering).
* How It Works 5-step visual guide.
* Downloadable PDF Business Plan presentation and marketing collateral.

### 2. Member User Dashboard
* **3X Earnings Cap Meter**: Visual progress tracking against the ₹18,900 cap limit.
* **Instant Activation via PIN**: Enter admin-generated activation PIN to activate account.
* **Wallet Management**: Real-time breakdown of Income Wallet, Withdrawal Wallet, Referral Bonus, Daily ROI, and Binary Pair Earnings.
* **KYC Upload & Verification**: Upload Aadhaar, PAN, and Bank details (IFSC, Account No, UPI).
* **Tax Invoices**: View product order status and print/download official GST Tax Invoices.
* **Support Ticket Center**: Communicate directly with corporate admin.

### 3. Interactive Genealogy Tree & Sandbox
* **Visual Binary Tree**: Zoom in/out, pan, collapse, search member ID, mini-map, and click-to-expand details drawer.
* **Leg Volume Stats**: Displays Member ID, Active Status, Left Volume (₹), Right Volume (₹), Lifetime Pairs, Today's Pairs, and Carry Forward.
* **Admin Sandbox Testing**: Add dummy members, move placement, delete nodes, run daily ROI triggers, and test binary pair matching live.

### 4. Admin Management Panel
* Total Users, Daily Joinings, Sales, Today's Pairs, ROI Paid, Pending Withdrawals, Pending KYCs.
* **PIN Engine**: Generate 12-character activation PINs in bulk and transfer PINs to member IDs.
* **Approval Queue**: Single-click approval for withdrawal payouts (with auto-deduction calculation) and KYC documents.
* **System Settings**: Adjust package price, pair income, daily ceiling, ROI rate, cap multiplier, and withdrawal deduction rates.
* **Database & Report Export**: Export reports to Excel/CSV or download the complete `wealth_veda.sql` database dump script.

* **Frontend**: React 19, TypeScript, Tailwind CSS, Motion (Framer Motion), Lucide Icons
* **Server & Logic**: Express.js Node backend engine with full MLM state persistence
* **Database Target**: MySQL 8.0+ / MariaDB (Script included: `wealth_veda.sql`)
